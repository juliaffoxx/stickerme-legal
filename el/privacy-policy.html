Πολιτική απορρήτου

Αυτή η πολιτική εξηγεί τι διατηρεί το StickerMe στη συσκευή σου, τι υποβάλλεται σε επεξεργασία στο cloud και πώς μπορείς να επικοινωνήσεις μαζί μας.

Τελευταία ενημέρωση: 25 Σεπτεμβρίου 2026

1. Ποιος παρέχει το StickerMe

Το StickerMe παρέχεται από τη Yuliia Otmakhova («εμείς»). Για ερωτήσεις απορρήτου ή αιτήματα σχετικά με δεδομένα, επικοινώνησε στο julia.artvision@gmail.com.

2. Πληροφορίες που αποθηκεύονται στη συσκευή σου

Τα αποθηκευμένα πακέτα αυτοκόλλητων, memes, καρικατούρες, οι αρχικές εικόνες που απαιτούνται για επεξεργασία ή επαναλήψεις, τα προφίλ της ενότητας «Άτομα», οι φωτογραφίες προφίλ και οι ρυθμίσεις δημιουργίας αποθηκεύονται στον τοπικό χώρο αποθήκευσης της εφαρμογής. Τα έτοιμα αυτοκόλλητα περιλαμβάνονται στην εφαρμογή. Μπορείς να διαγράψεις αποθηκευμένες δημιουργίες και προφίλ μέσα στην εφαρμογή. Η απεγκατάσταση του StickerMe αφαιρεί την τοπική βιβλιοθήκη και τα προφίλ του. Το StickerMe δεν ανεβάζει ολόκληρη τη βιβλιοθήκη φωτογραφιών σου.

3. Δημιουργία στο cloud

Όταν επιλέγεις να δημιουργήσεις περιεχόμενο, στέλνουμε την επιλεγμένη φωτογραφία ή ένα μικρότερο αντίγραφό της και τις ρυθμίσεις που έδωσες στο σύστημα υποστήριξής μας στο Google Firebase. Η δημιουργία αυτοκόλλητων και καρικατούρων μπορεί να περιλαμβάνει στοιχεία προφίλ του επιλεγμένου ατόμου και φωτογραφίες αναφοράς. Η δημιουργία memes χρησιμοποιεί μικρότερη φωτογραφία για ιδέες λεζάντας· η τελική απόδοση του meme γίνεται στη συσκευή σου. Το σύστημα υποστήριξης στέλνει τα σχετικά δεδομένα εισόδου στο OpenAI API για να παράγει το ζητούμενο αποτέλεσμα. Δεν χρησιμοποιούμε τις υποβληθείσες φωτογραφίες ή τα στοιχεία προφίλ για διαφήμιση.

Τα αρχεία εισόδου και εξόδου διατηρούνται σε ιδιωτικό προσωρινό χώρο αποθήκευσης cloud όσο εκτελείται μια εργασία και μέχρι η εφαρμογή να κατεβάσει και να επιβεβαιώσει το αποτέλεσμα. Έπειτα διαγράφουμε αυτά τα αντίγραφα· τα αρχεία που δεν έχουν παραληφθεί προγραμματίζονται για εκκαθάριση μετά από 24 ώρες. Διατηρούμε ένα τυχαίο αναγνωριστικό δημιουργίας, αποτύπωμα αιτήματος, κατάσταση εργασίας, αρχεία χρήσης και υπόλοιπο μονάδων για να παραδίδουμε αποτελέσματα, να αποτρέπουμε διπλές χρεώσεις και να εφαρμόζουμε τα δωρεάν όρια. Αυτές οι εγγραφές, που δεν αποτελούν αρχεία πολυμέσων, μπορούν να παραμείνουν μετά την απεγκατάσταση της εφαρμογής.

4. Ανώνυμη ταυτότητα και αγορές

Το StickerMe δημιουργεί ένα ανώνυμο αναγνωριστικό Firebase, ώστε ο διακομιστής να αναγνωρίζει τις δωρεάν παροχές σου, τις εργασίες και το πορτοφόλι μονάδων σου. Δεν σου ζητείται να δημιουργήσεις λογαριασμό με όνομα και κωδικό πρόσβασης. Ένα διαπιστευτήριο Keychain που αφορά μόνο τη συσκευή μπορεί να διατηρηθεί μετά από επανεγκατάσταση της εφαρμογής· δεν επαναφέρει διαγραμμένες τοπικές δημιουργίες. Η Apple επεξεργάζεται τις πληρωμές εντός της εφαρμογής. Η RevenueCat λαμβάνει το ανώνυμο αναγνωριστικό της εφαρμογής σου και στοιχεία αγοράς, όπως αναγνωριστικό προϊόντος, αναγνωριστικό συναλλαγής, ημερομηνία και κατάσταση αγοράς ή επιστροφής, ώστε να αποδίδονται οι μονάδες. Δεν λαμβάνουμε τον αριθμό της κάρτας πληρωμών σου.

5. Πάροχοι υπηρεσιών και τεχνικά δεδομένα

  • Τα Google Firebase και Google Cloud παρέχουν ανώνυμη πιστοποίηση, επεξεργασία εργασιών, προσωρινή αποθήκευση αρχείων και καταγραφές χρήσης. Μπορούν να επεξεργάζονται τεχνικά δεδομένα, όπως διεύθυνση IP και ώρα αιτήματος, για να παρέχουν και να προστατεύουν την υπηρεσία.
  • Το OpenAI επεξεργάζεται επιλεγμένα δεδομένα εισόδου και εξόδου δημιουργιών για να παράγει εικόνες ή λεζάντες. Στην επεξεργασία αυτή εφαρμόζονται οι πολιτικές δεδομένων API της OpenAI, συμπεριλαμβανομένης τυχόν διατήρησης για παρακολούθηση κατάχρησης.
  • Η RevenueCat διαχειρίζεται συμβάντα αγοράς και τη σύνδεση μεταξύ συναλλαγών Apple και του ανώνυμου αναγνωριστικού σου.
  • Η Apple επεξεργάζεται αγορές στο App Store και προαιρετικές ενέργειες στις Φωτογραφίες ή κοινοποίησης που επιλέγεις.

Η επεξεργασία μπορεί να πραγματοποιείται εκτός της χώρας σου. Χρησιμοποιούμε αυτούς τους παρόχους για τη λειτουργία του StickerMe· δεν πουλάμε προσωπικές πληροφορίες ούτε τις χρησιμοποιούμε για διαφήμιση μεταξύ εφαρμογών.

6. Οι επιλογές σου και η διαγραφή

Μπορείς να διαχειρίζεσαι τις άδειες κάμερας και Φωτογραφιών στις ρυθμίσεις iOS. Μπορείς να διαγράψεις δημιουργίες και προφίλ της ενότητας «Άτομα» μέσα στο StickerMe ή να απεγκαταστήσεις την εφαρμογή για να αφαιρέσεις τα τοπικά δεδομένα. Στην ενότητα «Ρυθμίσεις», επίλεξε Διαγραφή λογαριασμού cloud για να διαγράψεις τον ανώνυμο λογαριασμό Firebase, τις εγγραφές δημιουργίας του και τα προσωρινά αρχεία cloud. Η εφαρμογή δημιουργεί στη συνέχεια μια νέα ταυτότητα επισκέπτη αν συνεχίσεις να τη χρησιμοποιείς. Οι αχρησιμοποίητες μονάδες και οι μη ολοκληρωμένες δημιουργίες του διαγραμμένου λογαριασμού χάνονται· οι δημιουργίες που έχουν ήδη αποθηκευτεί στη συσκευή σου παραμένουν μέχρι να τις διαγράψεις ή να απεγκαταστήσεις την εφαρμογή. Ενδέχεται να διατηρούμε περιορισμένες εγγραφές συναλλαγών και ασφάλειας όταν απαιτούνται για επιστροφές, πρόληψη απάτης, λογιστική ή νομικές υποχρεώσεις. Για ερωτήσεις σχετικά με εγγραφές που διατηρούν οι πάροχοι υπηρεσιών μας, στείλε email στο julia.artvision@gmail.com.
