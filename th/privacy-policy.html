อัปเดตล่าสุด: 25 กันยายน 2026

1. ผู้ดำเนินการ StickerMe

StickerMe ให้บริการโดย Yuliia Otmakhova (“เรา”) หากมีคำถามด้านความเป็นส่วนตัวหรือคำขอเกี่ยวกับข้อมูล ให้ติดต่อ julia.artvision@gmail.com

2. ข้อมูลที่เก็บบนอุปกรณ์ของคุณ

ชุดสติกเกอร์ มีม ภาพล้อเลียนที่บันทึกไว้ ภาพต้นฉบับที่จำเป็นสำหรับการแก้ไขหรือสร้างซ้ำ โปรไฟล์ผู้คน รูปโปรไฟล์ และการตั้งค่าการสร้าง ถูกเก็บในพื้นที่จัดเก็บภายในเครื่องของแอป สติกเกอร์สำเร็จรูปมาพร้อมแอป คุณสามารถลบผลงานและโปรไฟล์ที่บันทึกไว้ในแอปได้ การถอนการติดตั้ง StickerMe จะลบคลังในเครื่องและโปรไฟล์ของแอป StickerMe ไม่อัปโหลดคลังรูปภาพทั้งหมดของคุณ

3. การสร้างบนคลาวด์

เมื่อคุณเลือกสร้างเนื้อหา เราจะส่งรูปที่เลือกหรือสำเนาที่ย่อขนาด พร้อมการตั้งค่าที่คุณระบุไปยังระบบหลังบ้าน Google Firebase ของเรา การสร้างสติกเกอร์และภาพล้อเลียนอาจรวมรายละเอียดโปรไฟล์และรูปอ้างอิงของบุคคลที่เลือก การสร้างมีมใช้รูปที่ย่อขนาดสำหรับแนวคิดคำบรรยาย ส่วนการประมวลผลภาพมีมขั้นสุดท้ายยังอยู่บนอุปกรณ์ของคุณ ระบบหลังบ้านส่งข้อมูลที่เกี่ยวข้องไปยัง OpenAI API เพื่อสร้างผลลัพธ์ที่ร้องขอ เราไม่ใช้รูปหรือรายละเอียดโปรไฟล์ที่ส่งมาเพื่อการโฆษณา

สื่อขาเข้าและขาออกจะถูกเก็บในพื้นที่จัดเก็บชั่วคราวบนคลาวด์แบบส่วนตัวระหว่างที่งานทำงาน จนกว่าแอปจะดาวน์โหลดและยืนยันการรับผลลัพธ์ จากนั้นเราจะลบสำเนาเหล่านั้น สื่อที่ยังไม่ได้รับจะถูกกำหนดให้ล้างหลังผ่านไป 24 ชั่วโมง เราเก็บรหัสการสร้างแบบสุ่ม ลายนิ้วมือของคำขอ สถานะงาน บันทึกการใช้งาน และยอดเครดิต เพื่อส่งมอบงาน ป้องกันการเรียกเก็บซ้ำ และบังคับใช้ขีดจำกัดฟรี บันทึกที่ไม่ใช่สื่อเหล่านี้อาจยังอยู่หลังถอนการติดตั้งแอป

4. ตัวตนนิรนามและการซื้อ

StickerMe สร้างรหัสประจำตัว Firebase แบบนิรนาม เพื่อให้เซิร์ฟเวอร์รู้จักโควตาฟรี งาน และกระเป๋าเครดิตของคุณ คุณไม่ต้องสร้างบัญชีที่ใช้ชื่อและรหัสผ่าน ข้อมูลรับรอง Keychain สำหรับอุปกรณ์เครื่องนั้นเท่านั้นอาจยังอยู่หลังติดตั้งแอปใหม่ แต่ไม่ได้คืนผลงานในเครื่องที่ถูกลบไป Apple จัดการการชำระเงินในแอป RevenueCat รับรหัสประจำตัวแอปแบบนิรนามและรายละเอียดการซื้อ เช่น รหัสผลิตภัณฑ์ รหัสธุรกรรม วันที่ และสถานะการซื้อหรือคืนเงิน เพื่อให้ส่งมอบเครดิตได้ เราไม่ได้รับหมายเลขบัตรชำระเงินของคุณ

5. ผู้ให้บริการและข้อมูลทางเทคนิค

  • Google Firebase และ Google Cloud ให้บริการการยืนยันตัวตนแบบนิรนาม การประมวลผลงาน การเก็บสื่อชั่วคราว และบันทึกการใช้งาน โดยอาจประมวลผลข้อมูลทางเทคนิค เช่น ที่อยู่ IP และเวลาคำขอ เพื่อให้บริการและรักษาความปลอดภัยของบริการ
  • OpenAI ประมวลผลข้อมูลขาเข้าและขาออกของการสร้างที่เลือกเพื่อสร้างภาพหรือคำบรรยาย นโยบายข้อมูล API ของ OpenAI รวมถึงการเก็บข้อมูลใด ๆ เพื่อเฝ้าระวังการใช้งานในทางที่ผิด มีผลกับการประมวลผลนี้
  • RevenueCat จัดการเหตุการณ์การซื้อและการเชื่อมโยงระหว่างธุรกรรม Apple กับรหัสประจำตัวแบบนิรนามของคุณ
  • Apple จัดการการซื้อใน App Store และการทำงานกับรูปภาพหรือการแชร์แบบเลือกได้ที่คุณเลือกใช้

การประมวลผลอาจเกิดขึ้นนอกประเทศของคุณ เราใช้ผู้ให้บริการเหล่านี้เพื่อดำเนินงาน StickerMe โดยไม่ขายข้อมูลส่วนบุคคลหรือใช้เพื่อการโฆษณาข้ามแอป

6. ทางเลือกและการลบข้อมูล

คุณจัดการสิทธิ์เข้าถึงกล้องและรูปภาพได้ในการตั้งค่า iOS คุณสามารถลบผลงานและโปรไฟล์ผู้คนใน StickerMe หรือถอนการติดตั้งแอปเพื่อลบข้อมูลในเครื่อง ในการตั้งค่า ให้เลือก ลบบัญชีคลาวด์ เพื่อลบบัญชี Firebase แบบนิรนาม บันทึกการสร้างของบัญชี และสื่อชั่วคราวบนคลาวด์ หลังจากนั้นแอปจะสร้างตัวตนผู้เยี่ยมชมใหม่หากคุณยังใช้แอปต่อ เครดิตที่ยังไม่ได้ใช้และการสร้างที่ยังไม่เสร็จในบัญชีที่ลบจะสูญหาย ส่วนผลงานที่บันทึกบนอุปกรณ์แล้วจะอยู่จนกว่าคุณจะลบหรือถอนการติดตั้งแอป เราอาจเก็บบันทึกธุรกรรมและความปลอดภัยในขอบเขตจำกัด เมื่อจำเป็นสำหรับการคืนเงิน ป้องกันการฉ้อโกง บัญชี หรือหน้าที่ตามกฎหมาย หากมีคำถามเกี่ยวกับบันทึกที่ผู้ให้บริการของเราเก็บไว้ ให้ส่งอีเมลถึง julia.artvision@gmail.com
